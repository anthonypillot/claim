# Claim Notifications

Claim announces game Giveaways to Discord communities. Existing Giveaway, Store, and Market
terminology is defined in [CONTEXT.md](./CONTEXT.md).

## Language

**Giveaway Occurrence**:
One distinct period in which a Store offers a game as a Giveaway in a Market. A later period for
the same game is a different occurrence; extending the current period does not create another.
_Avoid_: New game, listing

**Giveaway Alert**:
An announcement of a newly detected Giveaway Occurrence for a Discord Subscription.
_Avoid_: Digest, new-game notification

**Giveaway Alert Baseline**:
The active Giveaway Occurrences that a Discord Subscription begins following without receiving
Giveaway Alerts about them.
_Avoid_: Backlog, catch-up digest

**Discord Subscription**:
A Subscribed Channel's agreement to receive Giveaway Alerts from its selected Stores in its
selected Market.
_Avoid_: Mailing-list entry, recipient

**Subscribed Channel**:
A Discord server channel designated to receive Giveaway Alerts through a Discord Subscription.
_Avoid_: Subscriber, subscribed user
