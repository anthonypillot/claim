YAGNI / investigated and rejected

Do not collapse every Store folder

Their retrieval and mapping implementations have locality, and four adapters make the Store seam real. Deleting small index files saves little navigational mass.

Do not generate a shared response model yet

The web intake adapter already hides transport and validation behind a useful interface. Cross-workspace generation adds coupling for one response family.

Do not extract degraded rendering helpers

One renderer has direct coverage. A new pure module would be shallow and could repeat the filter invocation gap.

Do not generalize Store network readers

Session bootstrap, GraphQL, cookies, and discovery flows differ. Existing bounded readers provide the shared depth with better locality.

Top recommendation

Deepen the cache-scope lifecycle

It sits in the hottest change path, owns the most correctness-sensitive state, and offers the strongest locality and leverage gain without adding a speculative adapter or crossing documented feature ownership.
